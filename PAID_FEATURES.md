# Функции подписки оригинала

Проверка открытых надписей и ветвей клиента J-card/Cassette выполнена 03–04.10.2026. Платный аккаунт оригинала не использовался. В Cassette Studio перечисленные инструменты редактора доступны бесплатно.

| В оригинале за подпиской | В Cassette Studio 2.3.8 |
|---|---|
| PDF/PNG, копирование макета, печать, вылеты и форматы листов | Доступны; раскладка учитывается в PDF, PNG, SVG и копировании. |
| Отдельные декали: PNG и буфер изображений | Добавлены исходный размер и копирование в каталоге и свойствах картинки. Лист декалей экспортируется отдельно в 600 dpi. |
| Chalkpit J-card 3–8 панелей | Добавлен производственный шаблон с собственными размерами панелей и метками. |
| Chalkpit J-card ×8 SRA3 | Добавлен для стандартного J-card с 3 панелями; печатается лицевая сторона. |
| Chalkpit Cassette ×4 Jig | Добавлен для On Body / Full Body, по 4 корпуса на лист каждой стороны. |
| 12 наклеек на Letter с вылетами и без | Доступны отдельные варианты; PNG и копирование сохраняют раскладку листа. |
| Письмо для типографии | Добавлен PDF с параметрами печати, местом для подписи и необязательным QR. |
| Облачная библиотека: Starter 10, Partner 25, Patron без лимита | Пользователь выбрал папку OneDrive/Dropbox/Яндекс Диска. Проекты сохраняются со своими картинками и шрифтами; доступны открытие, переименование, избранное и обратимое удаление. Аккаунт облака оригинала не подключён. |
| Поиск без собственного лимита оригинала | Подписочного ограничения Cassette Studio нет. Доступность и квоты музыкальных сервисов продолжают действовать. |
| Короткие QR-ссылки с изменяемым адресом после печати | Пользователь решил оставить обычные QR-коды. Публичный сервер перенаправления не подключён. |
| Чаты и комнаты участников, отправка предложений | Это сообщество оригинала, а не инструмент печати. В приложении не воспроизводится. |

Загрузка своих изображений, обычное редактирование, свободное размещение, шрифты, 3D и режимы On Body / Full Body не подтверждены как отдельные платные возможности. В оригинале платным является их экспорт. Публикация Showcase и профиль требуют аккаунта, но их исключительная доступность по подписке не подтверждена.

У папки синхронизации нет тарифного лимита числа проектов. Список показывает до 2000 записей за раз; один проект ограничен 64 МБ. Файлы синхронизирует выбранная облачная программа. При получении новой версии файла приложение обнаруживает конфликт ревизий; одновременные изменения на отключённых компьютерах разрешаются также средствами облачной программы.

Источники: [J-card](https://vhs.texs.org/en/jcard), [Cassette](https://vhs.texs.org/en/cassette), [история изменений](https://vhs.texs.org/en/changelog), [публичные производственные форматы](https://vhs.texs.org/_next/static/chunks/3xv46-0fe6c3o.js). Исходный код сайта и его шаблонные картинки не включены в приложение; геометрия реализована независимо по открытым размерам.
