# Cassette Studio для Windows

Версия 2.4.5, Windows x64. Скачайте приложение в [GitHub Releases](https://github.com/dor1q/Cassette-Studio/releases/latest).

Верхнее меню **CD** открывает **CD Labels**, **CD Inserts (Cover)** и **CD Tray Card (Back)**. Размеры и стороны находятся в «Макете»; музыкальный импорт использует общий список треков. Инструкция и раскладки печати — в [CD_FORMATS.md](CD_FORMATS.md).

## Запуск

- [Cassette-Studio-2.4.5-Portable.exe](https://github.com/dor1q/Cassette-Studio/releases/download/v2.4.5/Cassette-Studio-2.4.5-Portable.exe) — откройте двойным щелчком. Установка не нужна.
- [Cassette-Studio-2.4.5-Setup.exe](https://github.com/dor1q/Cassette-Studio/releases/download/v2.4.5/Cassette-Studio-2.4.5-Setup.exe) — установщик с выбором папки и ярлыками.

Node.js и отдельный браузер для приложения не нужны. Оно запускает редактор в собственном окне. Интернет нужен для музыкальных каталогов, новых шрифтов, декалей, обложек и Spotify Codes. Выбранные изображения и шрифты встраиваются в проект; уже сохранённые макеты можно редактировать без интернета.

## Проекты и обновление

Приложение хранит проекты и настройки в `%APPDATA%\Cassette Studio`, отдельно от своей программы. Замена `.exe` и обновление приложения не удаляют проекты и подключения. При закрытии окна приложение завершает автосохранение. В распространяемые файлы личные настройки не включены; на другом компьютере подключения настраиваются в самой программе.

Проекты прежней браузерной версии не копируются автоматически. Откройте её библиотеку, сохраните нужный проект в JSON и выберите в приложении «Файл → Открыть проект». Для передачи проекта другому человеку используйте «Поделиться» и сохраните файл.

В меню «Файл» доступны открытие и сохранение проектов, библиотека, экспорт и печать. PDF, PNG, SVG и JSON сохраняются через обычное окно выбора папки Windows.


Загрузка и замена файла выполняются для выбранного при начале действия слоя и стороны. Если во время чтения был изменён макет или открыт другой проект, редактор попросит повторить действие. Загрузка картинки и добавление её в библиотеку отменяются одним нажатием Ctrl+Z. Фон добавляется под остальными элементами. Открытие JSON, локальной библиотеки, папки синхронизации и ссылки завершается после подготовки встроенных шрифтов; ошибка чтения или шрифта сохраняет текущий проект.

## Колонки и размещение из ссылок

В свойствах текста панели «Редактировать колонки вместе» включает общую рамку для перемещения, поворота, масштаба, стиля и копирования. Снимите галочку для настройки отдельной колонки. Если ссылка хранит приостановленное размещение, в «Макет» и «Слои» доступна кнопка «Возобновить размещение». Подробности — в [FIXES_2.3.9.md](FIXES_2.3.9.md).

## Обложки и галереи

При импорте нового альбома на обе стороны включённая галочка «Цвета обложки» подбирает фон по доминирующему цвету изображения и контрастный цвет текста. Фон J-card, оборота и обеих наклеек обновляется. «Сохранить дизайн» сохраняет расположение и шрифты независимо от этой галочки. Снимите «Цвета обложки», чтобы сохранить свои цвета. Подбор сохраняет отдельно окрашенные надписи, разделы, альбом на корешке и коды. Для уже загруженной обложки нажмите «Фон → Цвета из обложки»; это разовое действие работает и при выключенном автоматическом подборе. Импорт треков на одну сторону сохраняет цвета макета.

При импорте из музыкальных сервисов и загрузке файла обложка вписывается в рамку целиком с сохранением пропорций. При замене обложки прежние увеличение, сдвиг и поворот картинки сбрасываются; размер и положение рамки сохраняются. На уже загруженной обложке нажмите «Показать целиком» в настройках изображения. Свободное место вокруг картинки сохраняет фон макета. Для кадрирования выберите «Заполнить / обрезать» вручную. Явные параметры кадрирования в ссылках оригинального сайта продолжают переноситься.

Чтобы выбрать другую картинку, откройте «Фон → Выбрать обложку альбома». Галерея содержит основную обложку и доступные альтернативные изображения. Несколько размеров одной обложки считаются одним вариантом. Выбранная картинка вписывается целиком на открытой стороне. Закреплённую обложку сначала нужно открепить.

«Фон → Изображения альбома для фона» открывает отдельную коллекцию, включающую доступные картинки треков. Выбор добавляет новый фоновый слой на текущую сторону; его масштаб, прозрачность и остальные свойства можно изменить справа. Для разных наклеек A/B выключите синхронизацию оформления. При включённой синхронизации изменение передаётся на другую сторону.

В галереях показываются только изображения, которые отдал сервис. Основная обложка, варианты и картинки треков сохраняются в выбранных слоях проекта. Открытие ещё не выбранных изображений может требовать интернет. Недоступная картинка обозначается в галерее; при импорте ссылки оригинала с недоступным вариантом обложки редактор пробует основную и показывает предупреждение.

Чтобы увеличить или передвинуть обложку, используйте панель над макетом:

1. Нажмите «Обложка / фон» или выберите нужное изображение в соседнем списке. Список доступен и тогда, когда выбран текст или над картинкой лежат надписи.
2. Меняйте «Масштаб картинки» ползунком, кнопками «− / +» или колесом мыши над нужной деталью. При увеличении деталь остаётся под курсором.
3. Перетащите картинку внутри рамки. В этом режиме текст поверх изображения не перехватывает перемещение. Если режим выключен, нажмите «Перемещать картинку».
4. Нажмите Escape или «Завершить перемещение». «Целиком» сбрасывает кадрирование.

В свойствах справа также есть ползунок. Масштаб самого листа регулируется отдельно ползунком «Макет». При импорте обложка автоматически выбирается для редактирования. Закреплённая картинка доступна для выбора, но менять её масштаб и положение можно после снятия закрепления.


Закреплённые слои сохраняют свои размеры, оформление и скрытие при импорте нового альбома, даже если «Сохранить дизайн» выключено. Подбор цвета и команда общего цвета текста пропускают закреплённые элементы. Если на другой наклейке есть закреплённый слой, синхронизация A/B выключается с предупреждением; оформление этой стороны сохраняется.

Ссылки оригинала с `sai` и `sbi` загружают отдельный альбом или плейлист на A и B. Явные `musicA` / `musicB`, включая пустой список, имеют приоритет. Название кассеты и цвета остаются из ссылки; обложки отдельных источников пополняют галереи для выбора `mpN` и `tN`. Сохранённые списки и выбранные картинки можно восстановить без сети.

## Инструменты и проекты между компьютерами

Левое меню: «Содержимое», «Изображения», «Оформление», «Макет». В свойствах справа основное оформление доступно сразу; раскрывайте «Положение и размер» и «Оформление и эффекты», когда нужны дополнительные настройки.

Нажмите «Проекты → Облачная папка → Выбрать папку» и выберите папку синхронизации. Приложение создаст внутри «Cassette Studio Projects». На другом компьютере выберите ту же родительскую папку после завершения синхронизации. «Сохранить» и Ctrl+S используют выбранную библиотеку; переключение «На этом устройстве» возвращает локальное сохранение. Ctrl+Shift+S скачивает JSON. Автосохранение остаётся локальным и не отправляет промежуточные изменения в облако.

Доступны переименование, избранное и сохранение как копии. Удалённые собственные проекты перемещаются в «.trash»; отключение папки сохраняет файлы. При конфликте приложение предлагает обновить список или сохранить отдельную копию. Работа синхронизатора и одновременные автономные изменения зависят от вашего облачного сервиса. Один файл ограничен 64 МБ; список показывает до 2000 проектов за раз.

В «Cassette Label → Макет → Размеры и окно» выбираются Label / On Body / Full Body. Производственные раскладки и письмо для типографии находятся в «Экспорт / печать»; подробности — в [FIXES_2.3.8.md](FIXES_2.3.8.md).

Обычный экспорт PDF / PNG / SVG, копирование изображения и печать сохраняют макет без серой обводки. Чтобы добавить линии реза и сгиба, включите одноимённую галочку в окне «Экспорт / печать». В чистом шаблоне линии обязательны; производственные раскладки содержат собственные метки. Вылет продолжает учитывать выбранное значение.

## Альбом на корешке и текстовые панели

В импортированном J-card выберите «Текст → Корешок». Справа откройте «Альбом на корешке»: здесь задаются отдельные шрифт, размер, насыщенность, ширина и интервал букв, цвет, курсив, прописные, капитель, контур и тень названия альбома. «Google Fonts для альбома» и «Загрузить шрифт для альбома» меняют эту часть названия отдельно. «Общий цвет текста» возвращает наследование цвета; «Использовать стиль исполнителя» сбрасывает отдельное начертание. Выбранный файл шрифта сохраняется в проекте.

При переносе ссылки параметр `f3` задаёт этот отдельный стиль; приложение загружает доступное начертание вместе с основным шрифтом. Если нужного файла нет в каталоге, загрузите его самостоятельно. Переносы и ширина текста могут отличаться от оригинала.

Переносы учитывают жирное и курсивное начертание, капитель, интервалы и отдельный стиль альбома. Текст на скошенном клапане использует доступную ширину каждой строки. Измерения в приложении зависят от загруженного шрифта; автоматические проверки без браузера используют приближение.

Текстовые панели продолжают общий текст с внешней стороны на оборот. Скрытая панель сохраняет свою часть потока: следующая панель не получает её текст. Копии остаются связаны с исходной стороной, панелью и колонкой при изменении макета; видимая копия работает и при скрытом оригинале. Ручное положение и размеры, а также закреплённые блоки сохраняются при перерасчёте раскладки.

Для выбранного списка галочка «Выходные данные» управляет этой строкой. Во внутреннем содержимом строка добавляется один раз после списков и текстов песен. Собственные цвета стандартных блоков из `bx` сохраняются при подборе цветов нового альбома.

## Фоны и автоматический текст

Составной `bg` переносит цвет, изображение, прозрачность, повторение, масштаб и положение. Учитываются `bf`, `bm`, `bb`, `bgp`, `bgr`, дополнительные слои `bgl` и список файлов `cbl`. Доступны 8 узоров оригинала; AVIF из каталога фоновых узоров преобразуется в PNG. Известные идентификаторы изображений IGDB и SteamGridDB из исходной ссылки загружают соответствующую публичную картинку. Поиск этих каталогов требует собственных настроек в «Подключениях». Выбранные файлы встраиваются в JSON и могут повторно использоваться без сети. Закрытый `storage:` остаётся слоем для замены своим изображением.

Если изображение из ссылки не загрузилось, нажмите «Повторить загрузку изображений» в «Фон», «Макет», «Слои» или свойствах недоступной картинки. Повтор сохраняет текст, ручную рамку и закреплённые элементы. Фоновые индексы `tN` используют коллекцию и сохранённые изображения того же альбома; новая ссылка не подставляет кеш предыдущего альбома.

В «Фон → Фоны на этой стороне» выберите изображение. Справа можно включить повторение, настроить ширину и высоту плитки, размытие, режим наложения, непрозрачность, положение и поворот. Масштаб картинки регулируется ползунком или колесом. Маски панелей учитывают зеркальный оборот J-card; раздельные фоны A/B сохраняются без автоматического копирования, если исходная ссылка явно не включает синхронизацию. Фон находится под обложкой, а окно наклейки остаётся прозрачным и при экспорте.

Подбор цветов альбома меняет базовый цвет под узором. При включённом «Сохранить дизайн» сам узор сохраняется; его непрозрачность может скрывать новый цвет. Уменьшите непрозрачность изображения или отключите его видимость.

Во вкладке «Фон» галочка «Автоматический цвет текста» выбирает чёрный или белый отдельно по базовому цвету каждой стороны. Цвет меняется вместе с фоном; надписи с собственным цветом сохраняются. Подбор палитры нового альбома сохраняет включённый автоматический режим. «Применить цвет ко всем текстам» задаёт общий цвет всем текстовым блокам, включая название альбома на корешке. При переходе с импортированного `clear` на обычный цвет снова показывается текст, который был скрыт именно этим параметром.

В ссылках оригинала этот автоматический режим называется `rainbow`. Прежнее описание его как градиента исправлено. Функция градиента для J-card и Cassette Label не подтверждена; неизвестные источники внешних именованных галерей остаются отдельным ограничением. Полная карта параметров — в [REFERENCE_URL.md](REFERENCE_URL.md).

## Подключения

Открытые альбомы и отдельные треки Spotify загружают названия, исполнителей, длительности и обложки из публичного плеера без входа. Поддерживаются короткие ссылки, адреса с intl-ru и URI `spotify:album:<id>`, `spotify:track:<id>` и `spotify:playlist:<id>`. Публичный список плейлиста может быть ограничен Spotify; приложение показывает предупреждение. Для полного импорта своего или совместного плейлиста откройте «Подключения». Вход проходит в вашем обычном браузере. В Windows токен продолжения входа сохраняется с защитой текущего пользователя; после перезапуска вход восстанавливается. При смене Client ID прежняя сессия удаляется. Если защита Windows недоступна, сессия сохраняется только до закрытия приложения.

Apple Music учитывает регион ссылки и выбранную песню (`?i=`). Публичный адрес плейлиста Apple Music также можно вставить в импорт: вход и API-ключ не нужны. Редактор получает названия, длительности, основную обложку и доступные картинки треков из открытой страницы. При неполном списке, отсутствии общего числа треков или длительностей показывается предупреждение. Воспроизведение через встроенный плеер зависит от ограничений Apple Music и региона.

Deezer поддерживает альбомы, треки и публичные плейлисты без ключа. MusicBrainz импортирует конкретное издание; для группы с несколькими изданиями нужен выбор через поиск. YouTube и YouTube Music распознают watch, youtu.be, shorts, live и плейлисты. Без ключа отдельное видео отдаёт название и обложку; длительность остаётся неизвестной. Для длительности и списков плейлистов добавьте ключ YouTube Data API в «Подключениях».

Для поиска изображений IGDB добавьте собственные Client ID и Client Secret; для SteamGridDB — свой API-ключ. Поля находятся в «Подключениях». Во вкладке «Фон» нажмите «Поиск картинок IGDB / SteamGridDB», найдите игру и выберите изображение в её галерее: оно добавится фоновым слоем. Ключи хранятся отдельно от проекта. Без них программа сообщает, какой сервис нужно настроить; прямые поддерживаемые публичные адреса картинок могут работать без ключа. Живой поиск с личными ключами в этом выпуске не проверялся.

Временные сетевые ошибки повторяются автоматически. Если обложка большого размера недоступна, редактор пробует меньшую. Ошибка изображения не отменяет импорт треков. Если сервис не отдал весь список, редактор сообщает об этом. Наличие альтернативных обложек зависит от данных конкретного сервиса.

Адрес возврата Spotify показывается в «Подключениях». Обычно это `http://127.0.0.1:8769/api/spotify/callback`. Если этот адрес занят другой работающей копией локального редактора, приложение использует порт 8771; его адрес нужно разрешить в настройках вашего приложения Spotify.

## Форма кассетной наклейки

В текущей версии используются верхние скосы и прямые нижние углы исходного шаблона. Центр полностью прозрачный: фон, обложка, декали и коды обрезаются по общему контуру. В «Макете» должна быть включена настройка «Вырез под окно». Кнопка «Стандартный шаблон оригинала» восстанавливает стандартные размеры и включает окно, сохраняя надписи и изображения. Пользовательские размеры окна сохранённых проектов продолжают учитываться.

## Логотип лейбла и Remix

При импорте альбома приложение выбирает логотип Studio по реальному полю лейбла сервиса. При отсутствии данных, неоднозначности или недоступном логотипе используется Lo-Fi Stereo. Артист и copyright не определяют лейбл. Явный логотип или скрытие из ссылки, свой файл, замена, скрытие и закрепление сохраняются. Копия автоматического логотипа становится ручным элементом; её не меняют следующий альбом и автоматическая палитра.

Выберите Wild America Remix и нажмите «Перемешать Remix» в свойствах, чтобы получить новый рисунок. Складки J-card следуют границам панелей. Использованные части набора и seed сохраняются с проектом; тот же вариант можно повторить без сети. Интернет нужен для ещё не сохранённых частей нового варианта. Сборка остаётся независимой реализацией, её рисунок может отличаться от оригинала.

## Предпросмотр 3D

В 3D показаны корпус кассеты, катушки, лента, винты и отверстия, а также прозрачная коробка. Наклейка учитывает Label / On Body / Full Body; через прозрачное окно виден механизм. Размеры лицевой панели и корешка J-card учитывают проект. Для импортированного оборота выбирается зеркальная панель, в том числе при 3–8 панелях. Начальный масштаб подбирается по видимой области; «Сбросить вид» вписывает макет заново. Доступны обе стороны, полный экран и масштаб 10–140%. Геометрия, материалы и освещение приблизительные; корпус не добавляется в печатный макет.

## Проверки и ограничения

Текущие результаты проверки выпуска с CD приведены в [FIXES_2.4.5.md](FIXES_2.4.5.md). Проверки прежних кассетных форматов сохранены.

Новая проверка всех действий мышью не выполнена: средство управления браузером не запускается из-за ошибки прав чтения среды (`deny-read ACL`). Автоматические проверки и диагностика готового файла подтверждают только перечисленные сценарии. Они не являются полным сравнением Windows-интерфейса и не доказывают устранение любого возможного сбоя 0x80000003. Физическая печать не выполнялась; программа распространяется без сертификата цифровой подписи.

Полное совпадение с оригиналом не заявляется. Поиск IGDB/SteamGridDB требует собственных ключей; прочие внешние галереи поддержаны частично. Точные метрики шрифтов, рисунок Remix и материалы 3D могут отличаться. Закрытые облачные файлы требуют исходных изображений. Экспортные инструменты подписки реализованы бесплатно; библиотека между компьютерами использует выбранную папку синхронизации. Аккаунт, чаты и Showcase оригинала не подключены. Подробности — в [FIXES_2.3.8.md](FIXES_2.3.8.md) и [FEATURES.md](FEATURES.md).

## Для разработки

`npm ci`, затем `npm run desktop` — запуск. `npm run desktop:build` — сборка обеих версий в `dist-desktop`. `npm test` — проверки. Файлы редактора общие для Windows-приложения и локальной браузерной версии.

Для диагностики запуска предусмотрен `--smoke-test --studio-profile=<отдельная-папка>`. Проверка создаёт `startup-check.json` в указанной папке, загружает окно, файлы программы и дожидается готовности редактора. Флаг `--check-close` проверяет обычный запрос закрытия с завершением автосохранения и записывает `close-check.json`; повторный запуск с тем же отдельным профилем проверяет открытие сохранённого хранилища. С флагом `--check-music-import` дополнительно проверяются реальные музыкальные ссылки и обложки. Используйте отдельную папку профиля, чтобы не затронуть свою библиотеку. Диагностика не подтверждает визуальное совпадение макета.
